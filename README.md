# Death Road to Canada · Mac 中文汉化适配

将《加拿大死亡之路》（Death Road to Canada）已有的 **Windows 902.1 简体中文汉化补丁移植到 Steam Mac 版**，让 Mac 玩家使用原补丁的中文菜单、剧情和词条。

本项目只迁移原补丁已有的译文，没有自行续译新版内容。**这不是完整汉化，也不是游戏本体**。原补丁缺少的新版文字仍保留英文，使用者需要自行拥有对应版本的 Steam 游戏。

[下载安装包](https://github.com/MANJIblanc/death-road-to-canada-mac-zh/releases) · [详细使用说明](patch/先读我.md) · [原作者与转载说明](patch/来源与转载说明.md) · [未覆盖文本](patch/排查资料/未覆盖文本说明.md)

## 可以做什么

- 在 Mac 版中显示原 Windows 补丁已有的中文菜单、剧情、天赋、特质及其他可可靠对应的文字。
- 修复随机角色变化时中文词条不跟随刷新、动态属性提示漏译、长词条说明截断和部分句子前后缀迁移不全的问题。
- 提供 Mac 原生的安装、检查与还原工具，自动寻找默认和外置 Steam 游戏库；不需要另装 Python、Homebrew 或开发工具。
- 安装前核对版本与文件，备份原游戏及存档。遇到不匹配的版本或冲突文件时停止；安装中途失败时尝试回退。
- 保留当前 Mac 游戏内容、内部词条名称和存档格式。还原游戏文件时保留当前游玩进度。

## 安装和还原

1. 到 [Releases](https://github.com/MANJIblanc/death-road-to-canada-mac-zh/releases) 下载 `DR2C-Mac-Hans-build24936165-20261015.zip`，解压整个文件夹。
2. 完全退出游戏，双击 **安装汉化.command**。
3. 工具会自动寻找 Steam 游戏。如果找到多个，输入对应序号；没有找到时，把 **DR2C.app** 拖入窗口并按回车。
4. 看到“汉化已安装”后，从 Steam 正常启动游戏。

以后可以双击 **检查安装.command** 核对文件，或双击 **还原原版.command** 恢复安装前的游戏文件。三个 command 文件需要与 `Payload`、`工具` 文件夹放在一起。

备份与安装记录保存在当前用户的：

```text
~/Library/Application Support/DR2C-Mac-Hans
```

还原不会把存档倒退到安装前。如果以前装过其他补丁，应先使用对应工具还原原版。本工具不会强行覆盖无法识别的改动。

这是未经 Apple Developer ID 签名、公证的社区工具，macOS 可能给出打开提示。确认来源及校验值后，按系统提示对这个具体工具处理；不需要关闭整机安全检查。详细步骤和常见问题见 [使用说明](patch/先读我.md)。

## 已验证的内容

- 从干净游戏副本安装，235 个目标文件与已验证输出逐一一致。
- 完整备份、重复安装检查、从移动后的补丁目录还原；还原后原文件逐一一致，实际启动恢复英文菜单。
- 版本不符、补丁文件损坏、原文件冲突、游戏运行中等情况下停止覆盖；模拟中途失败后的回退和未完成安装的恢复。
- 原补丁 216 个句内片段的来源、5 个事件完整表达式，以及 130 组动态属性文字组合。
- 实际中文菜单、随机角色词条同步、正常开场、剧情及物资提示；音频代理的解码、播放和停止状态检查。
- 最终 ZIP 经 macOS 自带工具重新解压后，再次完成安装与还原。

没有逐一触发所有随机事件，音频没有人工试听。详见 [安装与还原验证记录](patch/排查资料/安装还原验证.json)。

## 覆盖范围

目前迁移了 **232 份脚本**中的原译文，提供 **13,049 条显示词库记录**。这些是记录数量，不能当作全游戏汉化百分比。

部分新版天赋／特质（如 Ranger、Chairmaster、Kensai、Duelist、The Big Shot、Hyperfixated、Craftsman）、39 条新版开场提示，以及部分新武器、事件和原生存档标题仍会显示英文。人物名字和内部标识也按原游戏保留。

[未覆盖文本说明](patch/排查资料/未覆盖文本说明.md) 与 [详细清单](patch/排查资料/未覆盖文本.json) 记录已知缺口。静态清单也包含人名、开发测试内容等，并不是“实际漏译总数”。

```text
patch/
  安装汉化.command / 检查安装.command / 还原原版.command
  Payload/       显示模块、原补丁字库及差异数据
  工具/          Mac 原生安装工具
  源码/          显示模块与安装工具源码、编译说明
  排查资料/      迁移来源、未覆盖文本及验证记录
```

安装包使用差异数据，从使用者自己拥有的原版文件在本机重建需要修改的脚本和音频代理。不携带游戏主程序、原版音频库、游戏音乐、完整原版脚本、个人存档或本机备份。
