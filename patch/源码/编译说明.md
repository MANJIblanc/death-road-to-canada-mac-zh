这些是本次 Mac 适配的实际源文件。游戏译文和字库来自原 Windows 补丁，权利归原作者。

显示模块保持 x86_64，使用原游戏架构。Apple Silicon 通过游戏已有的 Rosetta 运行。
安装工具同时编译 arm64 和 x86_64，不需要使用者安装 Python、Homebrew 或开发工具。

如需编译，安装 Xcode Command Line Tools，在此文件夹执行：

```sh
clang -arch x86_64 -mmacosx-version-min=11.0 -DADAPTER_SELF_TEST -Wno-deprecated-declarations -framework OpenGL dr2c_hans.c -o self_test
./self_test
```

正式显示模块的链接还需要使用者本机对应版本的 SDL2_mixer.original（由安装工具从本机原游戏生成）。编译命令如下，先将 ORIGINAL_AUDIO 设置为该文件路径：

```sh
clang -arch x86_64 -mmacosx-version-min=11.0 -dynamiclib -O2 -Wno-deprecated-declarations -framework OpenGL -Wl,-reexport_library,"$ORIGINAL_AUDIO" -Wl,-install_name,@rpath/SDL2_mixer.framework/Versions/A/SDL2_mixer -Wl,-compatibility_version,3.0.0 -Wl,-current_version,3.2.0 dr2c_hans.c -o SDL2_mixer
```

安装工具的编译命令（在解压后的补丁根目录执行）：

```sh
PAYLOAD_HASH=$(/usr/bin/shasum -a 256 Payload/patches.json | /usr/bin/cut -d ' ' -f 1)
clang -arch arm64 -arch x86_64 -mmacosx-version-min=11.0 -fobjc-arc -O2 -Wno-deprecated-declarations -DPAYLOAD_SHA256=\"$PAYLOAD_HASH\" -framework Foundation 源码/installer.m -o 工具/installer
codesign --force --sign - --timestamp=none 工具/installer
```

修改源码并不自动适配新游戏版本。固定地址、函数开头机器码和整个游戏主程序 SHA-256 必须重新检查；不要删除版本保护。
