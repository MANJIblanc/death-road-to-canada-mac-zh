# 加拿大死亡之路 Mac 汉化适配包

20261015.1 · 原 Windows 902.1 手动补丁迁移 · Steam build **24936165**

本包把原 Windows 汉化补丁已有的中文迁移到 Mac。没有自行续译新版内容，因此仍有部分英文，不能称为全游戏完整汉化。

## 适用范围

- 需要自己拥有 Steam Mac 版 Death Road to Canada。
- 只支持本次检查的 build 24936165 / TRACHEA，安装工具还会精确核对游戏程序和待改文件。版本不同会停止，游戏不变。
- 模块使用游戏原有的 x86_64 架构；Apple Silicon 使用游戏已有的 Rosetta。安装工具同时支持 arm64 与 x86_64。
- 编译最低系统为 macOS 11。实际游戏验证在 Apple Silicon、macOS 26.6.2 上完成；较旧 macOS 与 Intel 实机尚未验证。
- 安装者不需要安装 Python、Homebrew 或开发工具。工具需要对游戏目录有写入权限，请使用当前账户拥有的 Steam 游戏副本。

## 安装

1. 完全退出游戏，把整个压缩包解压到一个普通文件夹。
2. 双击 **安装汉化.command**。工具会寻找 Steam 的默认游戏目录和外置 Steam 库。
3. 找到一个游戏时自动安装；找到多个时输入序号。没有找到时，将 **DR2C.app** 拖入终端窗口并按回车。
4. 等待出现“汉化已安装”。以后从 Steam 正常启动即可。

不要只取出某个 command 文件；“工具”和“Payload”文件夹要留在一起。安装前会自动检查安装所需补丁文件、游戏版本及原文件，完整备份游戏、当前存档和 Steam 的该游戏存档索引，然后才替换游戏文件。安装失败会尝试自动还原；发生异常时请保留终端提示和备份。

如果以前手动安装过别的汉化，先使用对应工具还原原版。本包不会覆盖来历不明的已有改动，也不会删除之前的备份。Steam 更新或验证游戏完整性可能恢复原文件；此时先检查版本，再决定是否重新安装。

## 检查和还原

- 双击 **检查安装.command**：核对当前安装文件并显示备份位置。
- 双击 **还原原版.command**：恢复本工具安装前的原游戏文件，保留当前游玩进度。
- 解压文件夹移动后，仍能找到安装记录。备份保存在用户目录下的 `Library/Application Support/DR2C-Mac-Hans`，不在压缩包内。不要删除该目录，除非已经还原且不再需要备份。
- 还原不会把存档倒退到安装前。确实需要取回旧存档时，请先备份当前进度，再从工具显示的备份目录取出 `DR2C-saves`；不要在游戏运行时覆盖存档。
- 如果 Steam 已更新游戏，或待恢复的文件被其他模组改变，自动还原会停止以保护新文件。原备份仍会保留；请按提示处理，勿强行复制旧文件覆盖新版。

## macOS 打开提示

这是未取得 Apple Developer ID 签名及公证的社区适配工具。下载的文件可能被 macOS 提醒。确认文件来源及校验值后，可按系统提示对这个具体工具选择“仍要打开”；不要关闭整机的安全检查。若系统没有给出打开选项，请记录完整提示，交给分享者排查。

终端遇到“Permission denied”通常表示解压软件没有保留可执行权限，或 Steam 库不是当前账户可写。可先用 Finder 自带的归档实用工具重新解压；不要直接使用管理员权限强制覆盖游戏。

以下当前词条在原补丁中没有可靠的对应中文：Ranger、Chairmaster、Kensai、Duelist、The Big Shot、Hyperfixated、Craftsman。39 条新版开场提示、部分新武器／事件和原生存档标题等仍为英文。详见“排查资料/未覆盖文本说明.md”和“未覆盖文本.json”。静态清单含开发测试内容及人名，没有逐一触发全部随机事件。
